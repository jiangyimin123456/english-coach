# 英语学习网页：墨墨每日推送更新

将本文件夹内的 index.html、assets、.nojekyll 等内容上传到公开仓库 english-coach 的根目录，覆盖同名文件。不要上传外层文件夹或 ZIP 本身。
已有学习数据与授权在浏览器及私有仓库里，不在本更新包中。不要清除浏览器数据。刷新后会出现“墨墨每日词本”面板。

此网页只能展示统计和结果。电脑关机后执行的定时任务需要另行安装到私有仓库 english-coach-data，并配置 MAIMEMO_TOKEN Secret。

每日以北京时间22:00为目标，22:20和23:10补查。GitHub可能延迟；仅处理已同步的记录。22:00以后新建或修改的词顺延至下一次日截止时间。未推送的历史记录会补发，按原收藏日期分组。
只推送单词、短语和搭配（最长5词的简单英文表达），整句、归档、有冲突的记录不推送。已发送的词在网站归档后不会从墨墨删除。
同一个云词本使用 #0915 日期分组，跨年以 #20270915 区分。新词本默认未发布，需在墨墨检查是否可选词，按需自行发布或添加学习计划。程序不改变复习计划。
